# 柚子樂器商品影片固定品牌模板 v1

這個目錄是「實體圖與影片上傳」流程的固定影片資產，不能用近似圖、重畫圖或其他聲音代替。

- `youzi-intro-v1-3s-16x9.mp4`：3 秒片頭；柚子寶寶與 Logo 溫馨靠近後分開，使用定案的「暖木星光」音效。
- `youzi-watermark-green-v1.png`：主片期間使用的原始綠色透明 Logo，固定 13% 不透明度、畫面寬度 17%、右上角 2.5% 安全距離。
- `youzi-outro-v1-1.2s-16x9.mp4`：1.2 秒象牙白底 Logo 片尾，無聲。
- `profile-v1.json`：固定尺寸、時長、雜湊與兩平台輸出限制。

YouTube 使用完整主片；蝦皮成品包含片頭與片尾，因此主片最多只能使用 54.7 秒，總長不可超過 59 秒，檔案不可超過 30,000,000 bytes。

原始上傳影片永遠保留。品牌成品另存新檔，成功上架後把成品網址、SHA-256、品牌模板版本、時長、大小與平台回條寫回同一筆 `productVideos`，才能安全續跑且避免重複上傳。

固定執行程式：

```bash
python3 scripts/render-youzi-product-video.py 原始影片.mp4
```

原片超過 54.7 秒時，先看懂內容並找出最完整的一段，再加上 `--shopee-start 秒數`。若右上角剛好遮住商品或字幕，可使用 `--watermark-corner top-left`；除此以外不可自行改模板參數。
