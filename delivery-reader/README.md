# 配送資料讀取助手（只安裝在主機）

補讀 EasyStore 蝦皮通路訂單表格的物流商，解決一般訂單 API 只有 Shipping Fee 的缺口。
副機按「讀取最新訂單」後，主機重新查 API；若缺物流，就要求此助手讀取後台表格，一起傳回副機。

準備配對檔：
`node scripts/prepare-delivery-reader.cjs <主機助手資料夾> <主機 YouziShipping 資料夾>`
這會產生只適用此主機的 pairing.js 及 delivery-bridge.json，不可提交到 Git。

使用者在主機 Chrome 擴充功能管理頁開啟開發人員模式，選「載入未封裝項目」，選取準備好的助手資料夾。
保持主機 Chrome 開啟，並登入正確的 EasyStore 商店；副機不需要安裝。

助手只向 127.0.0.1:18765 取待查訂單編號，開啟背景 EasyStore 蝦皮通路訂單頁，讀取畫面上的物流欄。
以 EasyStore 訂單 ID 與蝦皮訂單編號雙重比對，最多查六頁，完成後關閉助手自己開啟的分頁。
不讀密碼、Cookie，不呼叫平台出貨、不列印、不改庫存。
新竹物流、店到家宅配、蝦皮店到店、超商與賣家配送均照後台實際文字顯示，不自行猜測。

登出、助手未啟動、逾時或頁面變動時，回報無法讀取。有效舊核對紀錄只能標為「上次核對」，不冒充本次結果。
每次更新都重新補讀，即使先前已有紀錄；正式 API 有物流時優先採用 API。

驗證必須在助手完成載入後，由副機按更新，確認新的核對時間與物流名稱同步變動。
單純人工填入 delivery-observations.json 或只測試介面，均不算助手已完成實機驗收。
