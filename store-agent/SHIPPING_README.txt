柚子樂器 出貨工作台 — 2026-10-20 第一版

使用方式
雙擊桌面「柚子樂器－出貨工作台」。
程式只在這台電腦的 http://127.0.0.1:18765 執行。
開啟時讀取近 3 天訂單（含今天）；畫面開著時每 5 分鐘重新讀取。
從營運中心「平台訂單 → 出貨工作台」開啟，與平台訂單共用側欄與配色。
同平台訂單集中排列，各平台內依時間由新到舊。預設只顯示「未處理」。
「取得貨運單」成功後保存為「已處理／已取單」；之後的按鈕改為「重印貨運單」。
開啟列印記為「已開啟列印」；按「我已印單」或「已印好，標記已印單」才記為已印單。
在其他平台印完可按「我已印單」；已交貨可按「我已出貨」。這是店內紀錄，不會替平台提交出貨。
MOMO 平台明確回傳已列印、或平台回傳已出貨的訂單，自動歸入已處理。
可用「移回未處理」更正操作。紀錄存於店內電腦，重新整理與重開仍保留。
訂單商品、地址或物流單號變更時，原處理紀錄不會套用到變更後的內容。
商品原始圖片、規格、件數放大；點擊圖片可再放大。收件與物流資訊可展開查看。
選取訂單後，可核對商品名稱、規格、SKU、數量、原始圖片和備註。
相同 SKU、品名、規格的商品合計數量；運費不列為實體包貨商品。
酷澎／MOMO 點「取得／重印貨運單」後，系統自動重新核對並取回文件，在同一個視窗顯示規格、SKU、件數和預覽。
酷澎新出貨若缺少物流公司或地址代碼，只需在同一視窗補齊；重印不會轉為新出貨。
酷澎新竹物流的側轉版面只在預覽轉正，正式列印保留原始 PDF。
蝦皮已出貨訂單新增「直接開啟蝦皮列印頁」，省略訂單明細頁。
尚未出貨的蝦皮訂單使用「到 EasyStore 出貨／印蝦皮單」入口。
在 EasyStore 選「出貨 → 透過蝦皮台灣出貨」，核對後才開始出貨處理；
成功後選「更多功能 → 列印蝦皮交貨便服務單」。完成後回工作台讀取最新訂單。
此入口仍需在 EasyStore 確認，尚不是工作台內一鍵出貨。工作台畫面已明確標示。

目前可用
1. EasyStore、MOMO、酷澎訂單集中讀取。蝦皮、官網、LINE 依原始來源分類。
   LINE 只有平台明確標記為 LINE 才分類；不以猜測將官網訂單改為 LINE。
2. MOMO：第三方物流、7-11、全家正式貨運單 API 已實作。
   已用真實「已列印」訂單測試重印成功。原始 PDF、官方明細合併 PDF 可取回。
   部分 MOMO PDF 需要供應商公司統編作為密碼。
3. 酷澎：已用真實「待寄出」訂單測試取回正式 PDF 成功。
   新出貨申請限商品準備中（INSTRUCT），需選物流與填寫平台登記地址代碼。
4. 包貨明細列印，保留訂單原始規格圖片。未提供圖片的商品標示「圖片待配對」。

尚未完成的部分
蝦皮／官網／LINE 的正式貨運單接口尚未接入。
目前已確認 EasyStore 後台可操作蝦皮出貨，但現有訂單讀取 token 並不等於
可在外部系統呼叫該後台功能。本版本不把手動寫入物流單號冒充申請正式貨運單。
需取得可用的蝦皮物流授權，或 EasyStore 提供的物流操作接口，才能完成此部分。
LINE 訂單若合併為官網來源，需平台提供原始通路標記。
酷澎/MOMO 的商品圖片依完整 SKU 從 EasyStore 商品資料配對：先用規格圖，沒有才用商品主圖。
主圖會標示「商品主圖」。SKU 無法唯一配對時不猜圖；編號只增加分隔線顯示，不改實際 SKU。
此版是單張操作，未提供批量申請出貨；超過 3 天的舊訂單不在預設查詢內。
新申請出貨流程有防重送及即時核對，但尚未用真實新訂單測試提交，
以免製作期間擅自產生出貨。正式使用前請選一筆確定要出貨的訂單驗收。

重要行為
同步／開啟畫面只讀取訂單，不改庫存或價格。
只有按「申請出貨與貨運單」或補齊資料後「確認出貨並取單」才提交平台。
送出逾時會保留未確認紀錄，不自動重送。
下載既有貨運單不會再次申請出貨。
列印包貨明細不等於列印正式物流單。正式單維持平台原始 PDF／HTML。
不得使用取消、異常或地址已變動的訂單申請出貨。

安裝與資料
shipping-workbench 資料夾置於原有店內同步程式資料夾內，與 config.json 同層。
使用原本 .venv 與 config.json；本套件不含任何金鑰或顧客資料。
運單及紀錄保存在 %LOCALAPPDATA%\YouziShipping，不公開到 GitHub。
執行 start_shipping.ps1 會啟動本機服務並開啟畫面。
僅綁定 127.0.0.1；精確 Host、Origin 與工作階段 cookie 檢查防止外部網站操作。
副機請使用 https://danny700808.github.io/play-card/shipping-desk.html ，以專用包貨密碼登入。
可勾選記住這台電腦，無須填姓名；只有包貨與取單功能，不提供後台管理入口。
副機指令經 HTTPS 傳給原主機，仍由原主機的固定 IP 呼叫平台；原主機需開機連線且保持登入 Windows。
原主機 Windows 登入後會啟動背景連線，不需要開著 Codex。
主機的「提供貨運單給副機」可上傳對應 EasyStore 訂單的官方 PDF，供副機預覽及列印。
PDF 預覽依賴 requirements-shipping-preview.txt；MOMO PDF 密碼可在主機的
%LOCALAPPDATA%\YouziShipping\document-settings.json 設定 momoPdfPassword，公司統編不會傳到公開前端。
設定後，主機以已提供的密碼產生可直接列印的 PDF 副本；不重新排版、不轉成圖片，
原始加密 PDF 仍供下載。副機的「開啟原單列印」使用免再次輸入密碼的副本。
預覽顯示第一頁，正式列印仍使用完整平台原單。瀏覽器不會自動指定 Windows 印表機，
第一次需在副機選好標籤機／一般印表機和紙張；印表機型號與紙張仍待現場確認。

測試
使用既有 .venv 執行：
python -m unittest test_shipping_workbench test_shipping_http -q
測試含取消/零件數阻擋、部分出貨、地址異動、防重送、
跨程序保留紀錄、正式文件保存、未授權存取與跨來源請求拒絕。
